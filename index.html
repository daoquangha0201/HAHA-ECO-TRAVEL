☁️ Đồng Bộ Đám Mây Realtime (Google Firebase)
⚪ Chế độ Cục bộ (Local Only)

Tự động đồng bộ tức thì 2 chiều giữa Máy tính và Điện thoại di động (PWA) qua 4G/5G/Wifi. Dữ liệu nhảy số ngay lập tức khi phát sinh đơn hàng, báo giá hoặc thu/chi!

Lần cuối: Chưa đồng bộ
💡 Hướng dẫn tạo Firebase Database miễn phí vĩnh viễn (chỉ 1 phút):
  1. Truy cập console.firebase.google.com và đăng nhập Gmail.
  2. Bấm Create a project (đặt tên ví dụ haha-travel-cloud) -> Tiếp tục đến khi tạo xong.
  3. Vào menu trái: Build -> Realtime Database -> Bấm Create Database (chọn Singapore).
  4. Tại tab Rules, đổi thành: { "rules": { ".read": true, ".write": true } } rồi bấm Publish.
  5. Sao chép đường dẫn (bắt đầu bằng https://...firebasedatabase.app) dán vào ô trên rồi bấm Lưu & Bật Kết Nối!
📥 1. Xuất file sao lưu (Export Database)

Tải về toàn bộ cơ sở dữ liệu hiện tại (Khách hàng, CTV, Tour, Đơn hàng, Thanh toán, Hoa hồng, Audit Log) dưới định dạng tệp JSON kèm mã kiểm tra toàn vẹn.

📤 2. Phục hồi dữ liệu (Restore Database)

Chọn tệp sao lưu JSON đã lưu để khôi phục. Hệ thống sẽ tự động kiểm tra tính toàn vẹn cấu trúc trước khi ghi nhận.

🧪 3. Bộ Kiểm Thử Tự Động Toàn Diện

Chạy tự động 20 nhóm kiểm thử: RBAC, Chống trùng lặp, Tính hoa hồng, Đối soát, Dòng tiền, Đơn tour 720M, Báo cáo Thuế và Chu trình chuyển giao liên phòng ban.
